# Smart Quiz AZ-900

**Study smarter. Understand every answer.**

Smart Quiz AZ-900 is an educational web application built for the #1MillionDevs Vibe Coding Hackathon. It helps learners prepare for the Microsoft Azure Fundamentals (AZ-900) certification through topic-based practice quizzes, instant feedback, and answer explanations.

## Live Demo

https://smart-quiz-az-900.vercel.app/

## GitHub Repository

https://github.com/siyanda940/smart-quiz-az-900

## Features

- **Topic-based practice:** Practise cloud concepts, Azure architecture and services, and Azure management and governance.
- **Flexible quizzes:** Choose a topic and the number of questions available for practice.
- **Instant feedback:** See whether your submitted answer is correct.
- **Answer explanations:** Learn why an answer is correct and understand the concepts behind it.
- **Results and scoring:** View your score, percentage, and incorrect-answer count.
- **Revision tools:** Access mistake review and weak-topic practice options.
- **Responsive interface:** A modern, learner-friendly interface designed for quiz practice.

## Technology

- React and TypeScript
- Vite / TanStack Start project tooling
- JSON-based question bank
- Vercel deployment
- GitHub version control

## AZ-900 Learning Topics

1. Describe cloud concepts
2. Describe Azure architecture and services
3. Describe Azure management and governance

## Getting Started

### Prerequisites

Install Node.js and npm.

### Run locally

```bash
git clone https://github.com/siyanda940/smart-quiz-az-900.git
cd smart-quiz-az-900
npm install
npm run dev
```

Open the local URL shown in your terminal.
